## 📌 Project Description (English)

This project analyzes the daily ridership data of the Metropolitan Transportation Authority (MTA) in New York City, covering subways, buses, commuter railroads, and bridges & tunnels.

The project follows the full data analysis workflow: cleaning and preprocessing the data with Power BI (Power Query), defining analysis questions that matter to decision makers, building an interactive Power BI dashboard, and forecasting ridership for the next month to support planning and operational decisions.

**Main objectives:**
- Clean and prepare the MTA ridership dataset for analysis.
- Identify ridership trends, busiest days, and seasonal patterns.
- Measure the recovery of each transport mode compared to pre-pandemic levels.
- Forecast the total ridership for the next month.
- Present the results in an interactive dashboard, a final report, and a presentation.

## 📌 وصف المشروع (بالعربي)

يقوم هذا المشروع بتحليل بيانات عدد الركاب اليومي لهيئة النقل في مدينة نيويورك (MTA)، وتشمل مترو الأنفاق والأتوبيسات وقطارات الضواحي والكباري والأنفاق.

يتبع المشروع خطوات تحليل البيانات الكاملة: تنظيف ومعالجة البيانات باستخدام Power BI (Power Query)، وتحديد أسئلة التحليل المهمة لمتخذي القرار، وبناء لوحة بيانات تفاعلية (Dashboard) بـ Power BI، والتنبؤ بعدد الركاب للشهر القادم لدعم قرارات التخطيط والتشغيل.

**أهداف المشروع:**
- تنظيف وتجهيز بيانات ركاب MTA للتحليل.
- اكتشاف اتجاهات الركاب وأكثر الأيام ازدحاماً والأنماط الموسمية.
- قياس مدى تعافي كل وسيلة نقل مقارنة بمستويات ما قبل كورونا.
- التنبؤ بإجمالي عدد الركاب للشهر القادم.
- عرض النتائج في داشبورد تفاعلي وتقرير نهائي وعرض تقديمي.
